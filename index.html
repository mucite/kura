Häufig gestellte Fragen

Ist Kura wirklich DSGVO-konform?

Ja, 100%. Kura führt die gesamte KI-Verarbeitung lokal auf Ihrem Computer durch.

  • Keine Patientendaten an externe Server
  • Audioaufnahmen werden automatisch gelöscht
  • Alle Daten bleiben auf Ihrem Computer

Welche Systemanforderungen gibt es?

macOS: Version 11+ (Intel oder Apple Silicon)
Windows: Version 10+ (64-bit)
RAM: Mindestens 8GB (empfohlen: 16GB)
Speicher: 7GB freier Speicherplatz

Bekomme ich Updates umsonst?

Ja! Solange Ihr Abo aktiv ist, erhalten Sie alle Updates automatisch.

Sie können jederzeit auf neue Versionen upgraden ohne zusätzliche Kosten.

Kann ich Kura auf mehreren Computern nutzen?

Ja! Die Lizenz ist hardware-gebunden.

  • Installation auf mehreren Macs/PCs möglich
  • Jeder Computer benötigt eine eigene Lizenz

Wie lang bleiben Befunde gespeichert?

Die Befunde werden lokal in Ihrem Archiv gespeichert und automatisch nach Patient organisiert.

  • Keine Weitergabe an Cloud-Services
  • Vollständige Datenkontrolle
  • Sie bestimmen die Aufbewahrungsdauer
